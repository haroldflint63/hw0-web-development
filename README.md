## 🎯 HTML Attributes Demonstrated

<details>
<summary><strong>Accessibility Attributes</strong></summary>

- `aria-label` - Provides accessible names
- `aria-describedby` - Links to descriptive text
- `role` - Defines element purpose (banner, main, navigation, etc.)
- `aria-live` - Announces dynamic content changes
</details>

<details>
<summary><strong>Form Attributes</strong></summary>

- `required` - Makes fields mandatory
- `minlength`/`maxlength` - Text length validation
- `min`/`max`/`step` - Number input constraints
- `placeholder` - Input hints
- `novalidate` - Custom validation handling
</details>

<details>
<summary><strong>Data and Custom Attributes</strong></summary>

- `data-*` - Custom data storage (data-color, data-label)
- `tabindex` - Keyboard navigation order
- `contenteditable` - Editable content areas
</details>

<details>
<summary><strong>Media and Link Attributes</strong></summary>

</details>

## 🚀 Getting Started

### Local Development

```bash
# Clone the repository
git clone https://github.com/haroldflint63/hw0-web-development.git

# Navigate to the project
cd hw0-web-development

# Open in your browser
open index.html
```

> 💡 **Note:** No build process required - vanilla HTML/CSS/JS! 

### GitHub Pages Deployment

1. Push code to GitHub repository
2. Go to repository **Settings** > **Pages**
3. Select source branch (main/master)
4. Site will be available at `https://haroldflint63.github.io/hw0-web-development`
